# State of Thought Website

Project website for **State of Thought (SoT)**.

## Local Preview

Run a local static server from this directory:

```bash
cd "/scratch/gongzhiren/MoT/papers/website"
python -m http.server 8080
```

Open:

`http://localhost:8080`

## Structure

- `index.html`: page content and section structure
- `styles.css`: visual theme and responsive layout
- `script.js`: lightbox, nav highlight, and case tabs
- `assets/`: figures converted from paper assets
